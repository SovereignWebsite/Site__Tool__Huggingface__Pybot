Try it

Try PyBot in your browser

This runs PyBot on your own computer. Python itself (through Pyodide, which compiles Python to WebAssembly) and PyBot's code are served from this site and run in a Web Worker in your browser. What you type is not sent anywhere.

Before you press the buttonIt downloads about 27 MB (PyBot's code about 13 MB, Python about 14 MB) and takes a while to start. In our test run (headless Chromium in a cloud container) it took 13.7 seconds.
PyBot can be wrongIt is built from rules, so it answers some things well and others badly. See the notes below the chat.
UnmodifiedThe code is PyBot's, unchanged, at commit 7d63c7f (16 November 2026), under the Apache License 2.0. Credits and licences.

    What we found when we ran it

    We built PyBot from its source and ran it twice on 27 November 2026 (about 01:32 to 01:35 UTC): in a terminal with Python 3.13, and in headless Chromium through Pyodide 0.27.7. Its own 12 tests passed (24 seconds). These are our runs, not PyBot's published figures.

    The same prompts, run twice. The browser run was not seeded, so wording can differ.
    PromptTerminal (seed 1)Browser (unseeded)
    hi, i'm Sam, then: what's my name?Remembered: "You're Sam."Remembered: "You're Sam."
    what is the capital of Portugal?"Lisbon.""Lisbon."
    how many legs does a spider haveWrong: a reply about housing a rabbit.Declined: "I'm not sure about that one, sorry".

    Timings: about 8 seconds for the first terminal reply including start-up, 1.4 to 2.3 seconds per turn after that; in the browser 13.7 seconds to start and 0.8 to 7.5 seconds per reply. One machine, one run each: treat these as examples, not benchmarks.
